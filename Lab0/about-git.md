1\. Чем ветка отличается от копии папки с проектом?



Ветка — это лёгкий указатель на определённый коммит внутри одного репозитория. Копия папки — это физическое дублирование всех файлов, которое занимает место и не хранит общую историю. Ветки позволяют вести параллельную разработку и легко сливать изменения через Git.





2\. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?



История полностью сохранится, потому что все коммиты, ветки и настройки хранятся в папке .git. Достаточно выполнить git checkout . или git restore ., чтобы восстановить последнюю зафиксированную версию файлов. Потеряются только незакоммиченные изменения.





3\. Зачем нужен Pull Request, если можно коммитить сразу в main?



PR позволяет проверить изменения до слияния: просмотреть diff, обсудить код, запустить автотесты и получить одобрение. Прямые коммиты в main опасны — ошибка сразу попадает в основную ветку. PR — это стандарт командной работы и точка контроля качества.
